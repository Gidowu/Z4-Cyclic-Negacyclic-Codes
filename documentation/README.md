# Computational Documentation

This repository contains Magma scripts and computational data associated with research on cyclic and negacyclic codes of even length over \(\mathbb{Z}_4\).

## Scripts

The `scripts/` directory contains programs used to generate and investigate codes, including their generators and parameters.

## Computational Data

The `data/` directory contains CSV files recording computational results.

- `data/cyclic/` contains results for cyclic codes.
- `data/oddly-even/` contains results from the oddly-even computations.

## Large Datasets

Some datasets are too large for direct upload through GitHub's web interface. These files are retained separately and will be linked here when their download locations are finalized.

## Reproducibility

The scripts and available data are provided to support inspection and reproduction of the computational experiments. Additional execution instructions and software requirements will be documented as they are verified.
